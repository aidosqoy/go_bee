# ДЗ 2.1: Zero values

## Цель
Понять концепцию нулевых значений в Go.

## Что нужно сделать

1. Объявить переменные всех базовых типов БЕЗ инициализации
2. Вывести их значения
3. Написать комментарий: зачем Go использует zero values вместо undefined/null

## Какие типы нужно проверить

- int, int8, int16, int32, int64
- uint, uint8, uint16, uint32, uint64
- float32, float64
- bool
- string

## Ожидаемый вывод (примерно)

```
int: 0
float64: 0
bool: false
string: ""
```

**Ответить письменно в комментарии:**
Почему в Go нет null/nil для базовых типов? Какие проблемы это решает?
